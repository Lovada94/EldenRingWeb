Bienvenido a Elden Ring Web

Explora el mundo de Elden Ring como nunca antes.

Esta web está basada en una API de Elden Ring que permite consultar información sobre armas, enemigos, objetos, misiones de personajes y mucho más.

Todos los derechos pertenecen a FromSoftware y Kadokawa Corporation. Este proyecto es únicamente con fines educativos.

Los usuarios registrados pueden guardar elementos en favoritos y, próximamente, crear y compartir builds personalizadas.
