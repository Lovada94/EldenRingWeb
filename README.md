# Elden Ring Web

Una aplicación web inspirada en el universo de Elden Ring donde los Sinluz pueden explorar, descubrir y gestionar información del juego.

## 🔥 Características

- Sistema de registro y login con autenticación JWT
- Protección de rutas y seguridad en API
- Arquitectura fullstack moderna (Angular + CodeIgniter)
- Gestión de usuario en tiempo real
- Base para futuras funcionalidades como builds, favoritos y guías

## ⚙️ Tecnologías

- Angular
- CodeIgniter 4
- MySQL
- JWT Authentication

## 🧭 Roadmap

- Perfil de usuario
- Sistema de favoritos
- Explorador de contenido (NPCs, armas, jefes, etc.)
- Builds personalizadas
